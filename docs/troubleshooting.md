## 常见报错

| 现象 | 处理 |
|------|------|
| 百度 `17` 今日请求量已达上限 | 免费额度用尽或配额不足，到控制台确认额度 |
| 百度 `18` 请求过于频繁 | QPS 超限，降低并发或稍后重试 |
| 百度 `110` / `111` | token 失效，插件会自动重签一次；仍失败请检查 Key 是否被重置 |
| 百度 `216202` | 图片过大（base64 后需 ≤4MB），先压缩或裁剪 |
| 腾讯 `AuthFailure.SignatureExpire` | 本机系统时间偏差过大，校准时间即可 |
| 腾讯 `RequestLimitExceeded` | 触发限流，插件会退避重试一次；仍失败请放慢批量速度 |
| 腾讯 `FailedOperation.ImageDecodeFailed` | 图片格式不支持（PNG / JPG / BMP，base64 后 ≤7MB） |
| 腾讯 `ResourceUnavailable.ResourcePackageRunOut` | 该接口资源包耗尽，需到控制台续购或换用其它接口 |
